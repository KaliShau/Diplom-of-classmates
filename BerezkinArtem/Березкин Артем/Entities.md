
___
### 🔹 Описание таблиц базы данных

1. Таблица `roles` (Роли)
	
	- `id` - уникальный идентификатор роли (первичный ключ)
	- `name` - название роли (уникальное, не может быть NULL)
	- `description` - описание роли

2. Таблица `users` (Пользователи)
	
	- `id` - уникальный идентификатор пользователя (первичный ключ)
	- `login` - логин пользователя (уникальный, не может быть NULL)
	- `password` - пароль пользователя (не может быть NULL)
	- `role_id` - ссылка на роль пользователя (внешний ключ к таблице roles)

3. Таблица `staff` (Персонал)
	
	- `id` - уникальный идентификатор сотрудника (первичный ключ)
	- `user_id` - ссылка на пользователя (уникальный внешний ключ к таблице users)
	- `full_name` - полное имя сотрудника (не может быть NULL)
	- `position` - должность (не может быть NULL)
	- `department` - отдел/подразделение (не может быть NULL)
	- `phone` - контактный телефон
	- `hire_date` - дата приема на работу (не может быть NULL)
	- `is_active` - статус активности (по умолчанию true)

4. Таблица `inventory` (Инвентарь)
	
	- `id` - уникальный идентификатор инвентаря (первичный ключ)
	- `name` - название предмета (не может быть NULL)
	- `category` - категория предмета (не может быть NULL)
	- `quantity` - количество
	- `unit` - единица измерения
	- `room` - помещение/комната
	- `status` - статус предмета

5. Таблица `suppliers` (Поставщики)
	
	- `id` - уникальный идентификатор поставщика (первичный ключ)
	- `name` - название поставщика (не может быть NULL)
	- `contact` - контактное лицо
	- `phone` - контактный телефон

6. Таблица `purchases` (Закупки)
	
	- `id` - уникальный идентификатор закупки (первичный ключ)
	- `supplier_id` - ссылка на поставщика (внешний ключ к таблице suppliers)
	- `item_name` - название закупаемого товара (не может быть NULL)
	- `quantity` - количество
	- `unit` - единица измерения
	- `price` - цена (текстовое поле)
	- `status` - статус закупки (текстовое поле)
	- `date` - дата закупки (не может быть NULL)

7. Таблица `requests` (Заявки на ремонт)
	
	- `id` - уникальный идентификатор заявки (первичный ключ)
	- `inventory_id` - ссылка на инвентарь (внешний ключ к таблице inventory)
	- `user_id` - ссылка на пользователя (внешний ключ к таблице users)
	- `date` - дата заявки (не может быть NULL)
	- `problem` - описание проблемы (не может быть NULL)
	- `status` - статус заявки (по умолчанию "Новая")

8. Таблица `work_schedule` (График работы)
	
	- `id` - уникальный идентификатор записи (первичный ключ)
	- `zone` - зона работы (текстовое поле)
	- `type` - тип работы (текстовое поле)
	- `staff_id` - ссылка на сотрудника (внешний ключ к таблице staff)
	- `day` - день работы (не может быть NULL)
	- `start_time` - время начала (не может быть NULL)
	- `end_time` - время окончания (не может быть NULL)

9. Таблица `buses` (Транспортные средства)
	
	- `id` - уникальный идентификатор автобуса (первичный ключ)
	- `model` - модель автобуса (не может быть NULL)
	- `license_plate` - номерной знак (уникальный, не может быть NULL)
	- `purchase_date` - дата покупки
	- `last_tech_inspection` - дата последнего техосмотра
	- `next_tech_inspection` - дата следующего техосмотра
	- `status` - статус автобуса (по умолчанию "active")
	- `notes` - примечания

10. Таблица `part_types` (Типы запчастей)
	
	- `id` - уникальный идентификатор типа запчасти (первичный ключ)
	- `name` - название запчасти (не может быть NULL)
	- `part_number` - номер запчасти (уникальный)
	- `description` - описание
	- `compatible_bus_models` - совместимые модели автобусов

11. Таблица `bus_parts` (Экземпляры запчастей)
	
	- `id` - уникальный идентификатор запчасти (первичный ключ)
	- `part_type_id` - ссылка на тип запчасти (не может быть NULL, внешний ключ к part_types)
	- `bus_id` - ссылка на автобус (не может быть NULL, внешний ключ к buses)
	- `serial_number` - серийный номер
	- `status` - статус запчасти (не может быть NULL)
	- `quantity` - количество
	- `unit` - единица измерения
	- `installation_date` - дата установки
	- `defect_date` - дата выявления дефекта
	- `defect_description` - описание дефекта

12. Таблица `part_operations` (Операции с запчастями)
	
	- `id` - уникальный идентификатор операции (первичный ключ)
	- `part_id` - ссылка на запчасть (внешний ключ к bus_parts)
	- `operation_type` - тип операции (не может быть NULL)
	- `bus_id` - ссылка на автобус (внешний ключ к buses)
	- `quantity` - количество
	- `unit` - единица измерения
	- `price` - цена (текстовое поле)
	- `operation_date` - дата операции (не может быть NULL)
	- `performed_by` - ссылка на сотрудника (внешний ключ к staff)
	- `supplier_id` - ссылка на поставщика (внешний ключ к suppliers)
	- `notes` - примечания
